Veille informatique

WebAssembly

WebAssembly (Wasm) est un format d'exécution binaire conçu pour faire tourner du code à des performances proches du natif directement dans le navigateur, en complément de JavaScript.

Pourquoi cette technologie m'intéresse

Elle permet d'exécuter des langages comme C, C++ ou Rust sur le web, ce qui ouvre la voie à des applications web plus performantes (jeux, outils de calcul, traitement d'images) tout en restant compatible avec les technologies que j'apprends actuellement.
